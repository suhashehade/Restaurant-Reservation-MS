## **Trigger Implementation** ##

### **Description** ###

Design a trigger to log an entry into a separate AuditLog table whenever a table get reserved. The AuditLog should capture ResturantId, TableId, ReservationDate and ChangeDate.


### **Create AuditLog table** ###

```sql
USE RestaurantReservationDB;
GO

CREATE TABLE AuditLog 
(
    AuditLogId INT IDENTITY(1,1) PRIMARY KEY,
    RestaurantId INT NOT NULL,
    TableId INT NOT NULL,
    ReservationDate DATETIME DEFAULT GETDATE() NOT NULL,
    ChangeDate DATETIME DEFAULT GETDATE() NOT NULL
);
GO
```

### **Trigger** ###

```sql
USE RestaurantReservationDB;
GO

CREATE TRIGGER tr_Logging
ON Reservations
AFTER INSERT
AS
BEGIN

   INSERT INTO AuditLog (RestaurantId, TableId, ReservationDate) 
   SELECT RestaurantId, TableId, ReservationDate
   FROM inserted;

END;
```

### **SQL Query** ###

```sql
INSERT INTO Reservations (RestaurantId, CustomerId, TableId, ReservationDate, PartySize)
    VALUES (
        30,
        158,
        60,
        DATEADD(DAY, 10, GETDATE()),
        (ABS(CHECKSUM(NEWID())) % 5) + 1
 );

SELECT * FROM AuditLog;
```

### **Rationale behind the query** ###

After create a table ```AuditLog```, I created a trigger on insert into ```Reservations``` table.

Once a reservation inserted the trigger get the inserted row using ```inserted``` logical table that created by SQL Server after the insertion.
 
To get the data from it I used ```SELECT``` and store the ```RestaurantId```, ```TableId```, and ```ReservationDate``` into AuditLog table, and the ChangeDate is generated by default as current date by using ```DEFAULT GETDATE()``` in table creation.

I tested the trigger by insert a row in ```Reservations``` and it insert the log immediately after the insertion, without needing to execute it manually.
